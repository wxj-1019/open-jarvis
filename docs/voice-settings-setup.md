1. 点击 **设置** 按钮（或按 `Ctrl+,`）

## ⚙️ 配置项说明

### 1. 语音识别 (STT) 设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| **识别引擎** | 选择语音识别服务 | OpenAI Whisper |
| **默认语言** | 语音识别的默认语言 | 中文 (简体) |
| **配置状态** | 显示是否已配置 API Key | - |

**支持的语言**：
- ✅ 中文 (简体) - zh-CN
- ✅ 中文 (繁体) - zh-TW
- ✅ English (US) - en-US
- ✅ 日本語 - ja-JP
- ✅ 한국어 - ko-KR

---

### 2. 语音合成 (TTS) 设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| **TTS 引擎** | 选择语音合成服务 | Xiaomi MiMo TTS |
| **TTS 模型** | 选择具体的 TTS 模型 | MiMo V2.5 TTS |
| **语速** | 语音播放速度 (0.5x - 2.0x) | 1.0x |
| **音调** | 语音音调高低 (0.5 - 2.0) | 1.0 |
| **音量** | 语音音量 (0% - 100%) | 100% |
| **测试语音** | 播放测试音频验证配置 | - |

**可用的 TTS 模型**：

| 模型 | 说明 | 推荐场景 |
|------|------|----------|
| **MiMo V2.5 TTS** | 最新 TTS 模型，高质量 | ✅ 日常使用（推荐） |
| **MiMo V2 TTS** | 上一代 TTS 模型 | 备选方案 |
| **MiMo V2.5 Voice Design** | 自定义音色设计 | 特殊语音风格 |
| **MiMo V2.5 Voice Clone** | 声音克隆 | 克隆特定声音 |

## 🔑 配置步骤

### 步骤 1：配置 API Keys

在 `.env` 文件中添加以下配置：

```env
# OpenAI API Key (用于语音识别)
OPENAI_API_KEY=sk-your-openai-key-here

# Mimo API Key (用于语音合成)
MIMO_API_KEY=your-mimo-key-here

# 可选：TTS 模型选择
MIMO_TTS_MODEL=mimo-v2.5-tts
```

**获取 API Key**：
- OpenAI: https://platform.openai.com/api-keys
- Mimo: https://dev.mi.com/mimo-open-platform

### 步骤 2：重启应用

```bash
# 停止当前应用 (Ctrl+C)
npm start
```

### 步骤 3：打开设置页面

1. 打开应用
2. 进入 **设置** → **🎤 语音**
3. 检查配置状态是否显示为"已配置"

### 步骤 4：测试语音功能

1. 调整语速、音调、音量
2. 点击 **"播放测试音频"** 按钮
3. 确认能听到测试语音

## 🔧 故障排除

### 问题 1：显示"未配置 OpenAI API Key"

**原因**：`.env` 文件中缺少 `OPENAI_API_KEY`

**解决**：
```env
OPENAI_API_KEY=sk-你的真实密钥
```

### 问题 2：显示"未配置 Mimo API Key"

**原因**：`.env` 文件中缺少 `MIMO_API_KEY`

**解决**：
```env
MIMO_API_KEY=你的Mimo密钥
```

### 问题 3：测试语音播放失败

**可能原因**：
1. API Key 无效
2. 网络连接问题
3. TTS 服务暂时不可用

**排查步骤**：
1. 检查浏览器控制台的错误信息
2. 验证 API Key 是否有效
3. 尝试切换 TTS 引擎为"浏览器内置"

### 问题 4：语音识别不准确

**优化建议**：
1. 确保麦克风权限已授予
2. 选择正确的识别语言
3. 在安静环境下使用
4. 说话清晰、语速适中
