# Open Jarvis 设置页面 UI/UX 优化 PRD

## 1. 产品概述

### 1.1 背景
Open Jarvis 设置页面当前采用基础的 Glassmorphism 设计风格，整体视觉较为平淡，缺乏产品特色展示。用户希望借鉴 Apple visionOS 空间计算风格，打造沉浸式的设置体验，同时突出产品的核心特色。

### 1.2 目标
- 采用 visionOS 玻璃拟态设计语言，增强视觉深度和层次感
- 突出四大产品特色：AI 助手个性化、多平台桥接能力、技能与插件生态、多模型支持
- 提升设置页面的视觉吸引力和用户体验
- 保持现有功能完整性的同时，重新定义视觉表达

## 2. 设计原则

### 2.1 visionOS 设计语言
- **玻璃拟态（Glassmorphism）**：多层半透明材质，背景模糊，营造空间感
- **深度层级（Depth Hierarchy）**：通过阴影、透明度、模糊度区分信息层级
- **材质系统（Material System）**：使用 ultraThin、thin、thick 三种玻璃材质
- **动态光效（Dynamic Lighting）**：模拟环境光在玻璃表面的折射效果
- **圆角与弧度**：统一的 20px 圆角系统，柔和流畅的视觉感受

### 2.2 产品特色表达
- **AI 助手个性化**：Agent 卡片采用 3D 悬浮效果，展示角色特质
- **多平台桥接**：连接状态可视化，动态脉冲效果
- **技能与插件生态**：网格化展示，分类标签系统
- **多模型支持**：供应商卡片化，能力指标可视化

## 3. 核心功能优化

### 3.1 导航栏优化
**当前问题**：
- 简单的列表式导航，缺乏视觉层次
- 激活状态仅靠背景色区分，不够醒目

**优化方案**：
- 采用 visionOS 侧边栏风格，半透明玻璃背景
- 激活项增加左侧指示条（类似 macOS 设置）
- 图标增加微光效果，hover 时轻微放大
- 分组标题采用大写字母+字间距，增强可读性

### 3.2 内容区域优化
**当前问题**：
- 内容区域过于扁平，缺乏视觉焦点
- Section 卡片样式单一

**优化方案**：
- 顶部标题采用 SF Pro Display 字体，大字号+粗体
- Section 卡片采用 visionOS thin material 风格
- 卡片 hover 时增加光晕效果（glow）
- 关键信息采用胶囊（Capsule）样式展示

### 3.3 特色功能展示

#### 3.3.1 Agent 个性化展示
- Agent 卡片采用 3D 翻转效果
- 增加角色特质标签（类似 Apple Music 艺人卡片）
- 记忆/经验模块采用进度环展示
- 角色预览增加全屏悬浮效果

#### 3.3.2 多平台桥接展示
- 平台连接状态采用动态指示灯
- 连接成功增加脉冲动画
- 平台图标采用圆角方形，类似 macOS Dock

#### 3.3.3 技能与插件生态
- 技能采用图标+名称的网格布局
- 安装状态采用徽章系统
- 热门技能增加推荐标签

#### 3.3.4 多模型支持
- 供应商采用卡片式展示
- 能力指标采用进度条+数值
- 模型切换采用分段控制器（Segmented Control）

## 4. 视觉规范

### 4.1 色彩系统
```css
:root {
  /* visionOS Material Colors */
  --glass-ultra-thin: rgba(255, 255, 255, 0.65);
  --glass-thin: rgba(255, 255, 255, 0.75);
  --glass-thick: rgba(255, 255, 255, 0.85);
  
  /* 动态光效 */
  --glow-primary: rgba(0, 122, 255, 0.15);
  --glow-success: rgba(52, 199, 89, 0.15);
  --glow-warning: rgba(255, 149, 0, 0.15);
  
  /* 深度阴影 */
  --shadow-depth-1: 0 2px 8px rgba(0, 0, 0, 0.04);
  --shadow-depth-2: 0 4px 16px rgba(0, 0, 0, 0.08);
  --shadow-depth-3: 0 8px 32px rgba(0, 0, 0, 0.12);
  
  /* 边框 */
  --glass-border: rgba(255, 255, 255, 0.2);
  --glass-border-dark: rgba(0, 0, 0, 0.08);
}
```

### 4.2 圆角系统
```css
:root {
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --radius-xl: 20px;
  --radius-capsule: 999px;
}
```

### 4.3 字体规范
- 标题：-apple-system, BlinkMacSystemFont, "SF Pro Display", 28px, 700
- 副标题：-apple-system, BlinkMacSystemFont, "SF Pro Text", 17px, 600
- 正文：-apple-system, BlinkMacSystemFont, "SF Pro Text", 15px, 400
- 说明：-apple-system, BlinkMacSystemFont, "SF Pro Text", 13px, 400

### 4.4 动效规范
- 页面切换：0.3s ease-out
- 卡片 hover：0.2s ease
- 状态指示：脉冲动画 2s 循环
- 加载状态：骨架屏 + 微光扫光

## 5. 交互优化

### 5.1 导航交互
- 点击导航项时，内容区平滑滚动到对应 Section
- 滚动时导航项高亮自动更新
- 支持键盘导航（↑↓ 切换，Enter 确认）

### 5.2 卡片交互
- 卡片 hover 时微微上浮（transform: translateY(-2px)）
- 点击卡片时增加按压缩放效果（scale: 0.98）
- 长按显示快捷菜单（类似 macOS 右键）

### 5.3 状态反馈
- 操作成功：顶部 Toast + 绿色光晕
- 操作失败：顶部 Toast + 红色光晕
- 加载中：骨架屏 + 微光扫光

## 6. 技术实现要点

### 6.1 玻璃拟态实现
- 使用 `backdrop-filter: blur()` 实现背景模糊
- 多层半透明叠加营造深度
- 动态背景渐变增加空间感

### 6.2 动效实现
- 优先使用 CSS transitions/animations
- 复杂动画使用 requestAnimationFrame
- 尊重用户的 prefers-reduced-motion 设置

### 6.3 性能优化
- 玻璃效果使用 will-change 优化
- 图片使用懒加载
- 虚拟滚动长列表
